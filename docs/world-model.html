01 / WORLD MODEL

物理约束的多模态世界模型

将多源感知信息压缩为可推演的潜在状态，并在未来状态生成中引入车辆运动与道路安全约束，为后续规划提供一致的环境表征。

多模态时空表征

联合建模多视角视觉、激光雷达、车辆状态和道路拓扑，提取交通参与者与道路结构信息。循环状态空间模型在潜在空间中保持跨时刻的一致性，为连续推演提供状态基础。

物理先验约束推演

扩散生成过程结合车辆运动学、道路边界和安全约束，对多主体未来状态进行条件推演。模型在表达复杂交互变化的同时，约束不合理运动和越界轨迹。

服务闭环决策

决策模块可以在潜在空间中评估候选行为的未来后果，将预测结果转化为轨迹收益与风险判断，并随新的观测滚动更新。

KEY MECHANISM

连续控制与物理一致性

世界模型在潜在空间中递推未来状态，并用残差动作表达相邻控制周期的变化。这样，零残差对应保持上一时刻动作，便于生成连续的转向和加减速序列。

生成轨迹还接受速度、加速度变化、道路边界及安全时距等约束校验；当多次推演结果分歧增大时，系统可缩短推演时域并结合真实观测修正预测。

残差动作更新
at = tanh(atanh(at−1) + Δut)

at−1 为上一控制动作，Δut 为潜空间中的动作增量。约束作用于推演轨迹，而非只检查单帧状态。
